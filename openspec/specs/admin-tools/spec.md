# admin-tools Specification

## Purpose
Админские возможности поверх тех же `/api/reports/*` без отдельных копий
отчётов: просмотр отчётов как клиент, агрегаты по пользователям и просмотр
иконок пользователя. Пути остаются под `/api/reports/*`, чтобы не менять
маршрутизацию wallet-gateway.

## Requirements

### Requirement: Просмотр как клиент через as_user_id
Любой отчётный эндпоинт `GET /api/reports/*` SHALL принимать необязательный
параметр `as_user_id`. Для роли `admin` отчёт SHALL строиться по леджеру
указанного пользователя тем же кодом и той же формой ответа.

#### Scenario: Админ смотрит чужой леджер
- **WHEN** пользователь с `role=admin` вызывает отчёт с `as_user_id=<uuid>`
- **THEN** отчёт строится по леджеру пользователя `<uuid>`

#### Scenario: Не-админ передаёт as_user_id
- **WHEN** пользователь с ролью, отличной от `admin`, передаёт непустой `as_user_id`
- **THEN** 403, параметр не игнорируется молча

#### Scenario: Параметр не передан или пуст
- **WHEN** `as_user_id` отсутствует или пуст
- **THEN** отчёт строится по собственному леджеру вызывающего

#### Scenario: У целевого пользователя нет леджера
- **WHEN** админ передаёт `as_user_id` пользователя без леджера
- **THEN** 200 с пустым отчётом, как у самого такого пользователя

### Requirement: Аудит просмотра как клиент
Каждый вызов с `as_user_id` от админа SHALL записываться в лог отдельной
строкой с `event: admin_view_as`, `admin_user_id` и `target_user_id`.

#### Scenario: Аудит-запись
- **WHEN** админ вызывает отчёт с `as_user_id`
- **THEN** в лог пишется запись `admin_view_as` с id админа и целевого пользователя

### Requirement: Просмотр под собственным токеном администратора
Режим просмотра как клиент SHALL включаться только параметром `as_user_id`
при собственном токене администратора: личность и права вызывающего
определяются по `sub`/`role` этого токена, целевой пользователь — только по
`as_user_id`. Сервис MUST NOT требовать или выпускать токен на целевого
пользователя (имперсонацию с чужим `sub`), и режим SHALL распространяться
только на чтение отчётов wallet-report.

#### Scenario: Личность вызывающего в аудите
- **WHEN** админ вызывает отчёт со своим токеном и `as_user_id=<uuid>`
- **THEN** `admin_user_id` в аудит-записи равен `sub` токена, `target_user_id` — `<uuid>`

#### Scenario: Права проверяются по вызывающему
- **WHEN** пользователь без роли `admin` передаёт `as_user_id` администратора
- **THEN** 403: роль целевого пользователя права вызывающего не расширяет

#### Scenario: Только чтение
- **WHEN** админ работает в режиме просмотра
- **THEN** доступны только отчёты `GET /api/reports/*`; эндпоинтов записи от имени целевого пользователя у сервиса нет

### Requirement: Агрегаты по переданным пользователям
`POST /api/reports/admin/users/stats` с телом `{"user_ids": [...]}` SHALL
возвращать по одной строке на каждого переданного пользователя, владеющего
леджером: число кошельков, число операций, даты первой и последней операции,
число участников леджера. Считается одним запросом только по леджерам этих
пользователей. Доступ только для `role=admin`.

#### Scenario: Пользователь без леджера
- **WHEN** среди `user_ids` есть пользователь без леджера
- **THEN** строки для него в ответе нет

#### Scenario: Некорректное тело
- **WHEN** тело не объект с массивом `user_ids`, в массиве больше 5000 элементов или элемент не UUID-строка
- **THEN** 400

#### Scenario: Не-админ
- **WHEN** вызывает пользователь с ролью, отличной от `admin` (включая `support`)
- **THEN** 403

#### Scenario: Без токена
- **WHEN** запрос без валидного токена
- **THEN** 401

### Requirement: Иконки пользователя для админа
`GET /api/reports/admin/icons` SHALL быть доступен только `role=admin` и
возвращать общий набор иконок, а при переданном `user_id` — дополнительно
собственные иконки леджера этого пользователя.

#### Scenario: Без user_id
- **WHEN** админ вызывает эндпоинт без `user_id`
- **THEN** возвращается общий набор, `user: []`

#### Scenario: Пользователь без леджера
- **WHEN** передан `user_id` пользователя без леджера
- **THEN** 404

#### Scenario: Не-админ
- **WHEN** вызывает пользователь с ролью, отличной от `admin`
- **THEN** 403
