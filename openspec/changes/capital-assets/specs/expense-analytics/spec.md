# Spec Delta

## ADDED Requirements

### Requirement: Переоценка вне аналитики расхода
`/expense-structure` и `/expense-biggest-moves` SHALL не учитывать проводки
«актив → Переоценка» (категория с `system_kind = 3`): категория «Переоценка»
не появляется среди категорий расхода и не влияет на `total_eq` и доли
остальных категорий.

#### Scenario: Износ машины в периоде
- **WHEN** в периоде есть расход на «Продукты» 30 000 и проводка «Машина → Переоценка» на 300 000
- **THEN** структура содержит только «Продукты» с долей `"100.0"` и `total_eq` = 30 000

#### Scenario: Топ изменений
- **WHEN** переоценка вниз есть только в одном из двух сравниваемых периодов
- **THEN** «Переоценка» не попадает в `/expense-biggest-moves`
