# Proposal

## Why

Отчёты считают эквивалент по курсу из вьюхи `v_currency_conversion_rate`
(владелец — wallet-api). Для валюты без прямой пары к валюте эквивалента
(например, BTC → RUB при наличии BTC/EUR и EUR/RUB) курса нет, и строка
отчёта остаётся без эквивалента. В wallet-api вводятся маршруты пересчёта через
промежуточную валюту (одноимённый change), и курс для них начнёт считаться
составным — отчёты должны это корректно потребить и сохранить
поведение «нет курса — нет эквивалента» там, где маршрута нет.

## What Changes

- Запросы отчётов не переписываются: они зовут SQL-функции wallet-api
  (`f_balance_*`, `f_assets_for_period`, `f_debts_for_period`), а те в
  одноимённом change wallet-api переведены на функцию `rate_on` (прямой курс →
  маршрут → кросс через USD; вариант «составные строки во вьюхе» заменён по
  итогам замера) и получают составные курсы автоматически. Проверяется, что
  выбор «последний курс ≤ даты, прямая пара приоритетнее» в запросах `balance`,
  `balance-at-dates`, `balance-series`, капитал и долги работает с маршрутами
  (дубли строк на кошелёк и бакет недопустимы).
- Тестовый зеркальный протокол синка (`sync_repo.cpp`, список колонок
  `currency_conversion`) приводится к новой форме таблицы из wallet-api, чтобы
  интеграционные тесты могли засевать маршруты. В исполняемый файл
  `wallet_report` этот код по-прежнему не входит.
- Добавляются интеграционные тесты: эквивалент по маршруту, приоритет прямой
  пары, отсутствие эквивалента при обрыве маршрута (нет курса на втором шаге),
  отсутствие дублей.
- Контракт HTTP-ответов не меняется: те же поля, строки без курса
  по-прежнему помечаются как не пересчитанные.

## Impact

- Код: `src/sync_repo.cpp` (колонки `currency_conversion`, только для тестов),
  `tests_integration/test_reports.cpp` (новые сценарии).
- Зависимость: миграция и вьюхи wallet-api. Порядок выката: wallet-api →
  wallet-report. Разовая проверка планов запросов серий на вьюхе с
  составными строками.
- Смежные change с тем же именем: wallet-api, android-wallet, wallet-web.
  wallet-mcp, wallet-telegram и wallet-gateway не затронуты: они берут
  эквиваленты из ответов wallet-report.
