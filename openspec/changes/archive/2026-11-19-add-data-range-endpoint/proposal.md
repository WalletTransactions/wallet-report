# Proposal

## Why

wallet-mcp хочет отдавать модели период, за который в леджере есть данные
(инструмент `ledger_overview`, change `add-ledger-overview-tool` в wallet-mcp).
Существующие эндпоинты отдают операции только по убыванию даты с курсором, и найти
первую операцию можно лишь обходом всех страниц. Нужен один дешёвый агрегат.

## What Changes

- Новый эндпоинт `GET /api/reports/data-range`: дата первой и последней живой операции леджера и число таких операций. У пустого леджера (и у пользователя без леджера) даты `null`, число `0`.
- Запись в `openapi.yaml` и строка в таблице эндпоинтов `README.md`.

## Capabilities

### New Capabilities

Нет.

### Modified Capabilities

- `reference-data`: новое требование «Диапазон данных леджера».

## Impact

- `wallet-report`: новый хендлер, функция `reports_repo::data_range`, интеграционный тест.
- Остальные сервисы не меняются: путь под `/api/reports/*`, гейтвей маршрутизирует его без правок. Схема БД и роль `wallet_reader` те же (читаем `operation`).
- Потребитель — wallet-mcp (`ledger_overview`); он выкатывается после этого сервиса.
